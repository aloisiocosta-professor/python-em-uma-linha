Use Python para conferir seu raciocínio

O exemplo está em uma linha física. A explicação tem o espaço necessário. Primeiro acompanhe a ideia; não é preciso decorar essa escrita. Aprender a criar e executar um arquivo.

Baixar .py
print(2+3==6)

Acompanhe o mecanismo

  1. Alguém prevê que 2+3 seja 6.
  2. A conta produz 5; == compara esse valor com 6.
  3. False mostra que a comparação falhou; precisamos corrigir a previsão ou a regra declarada.

Antes de conferir, preveja o resultado e explique por quê. Se baixou só este arquivo, use python z11.py no terminal da pasta onde o salvou. Se obteve o repositório inteiro, use python examples/z11.py na pasta principal. Use o nome de comando Python 3 identificado na preparação.

Conferir a saída esperada
False
