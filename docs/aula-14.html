Ordenação por partição

Escolha o primeiro elemento como pivô; separe os menores e os demais. Ordene recursivamente ambas as partes e concatene esquerda, pivô e direita. A entrada vazia é o caso base.

Objetivo desta aula

Explicar ordenação por partição, prever o resultado do exemplo e modificar uma hipótese de entrada sem romper a regra de uma linha física.

Seu arquivo de uma linha

Salve como examples/14.py. A rolagem ou quebra visual na tela não muda o arquivo.

Baixar .py
q=lambda xs:q([x for x in xs[1:] if x<xs[0]])+xs[:1]+q([x for x in xs[1:] if x>=xs[0]]) if xs else [];print(q([3,1,3,2]))

Leia e execute

Leia as instruções separadas por ; da esquerda para a direita. Dentro de uma chamada, os argumentos são avaliados antes de a função ser executada. Uma compreensão percorre a fonte e aplica seu filtro antes da transformação.

No terminal: python examples/14.py. Compare o resultado com o oráculo abaixo antes de modificar o programa.

[1, 2, 3, 3]

Exercício

O que acontece com os elementos iguais ao pivô?

Conferir resposta comentada

Entram na partição direita e continuam presentes, preservando a multiplicidade.

Hipóteses e limites

Esta versão didática não deve ser usada para recursões muito profundas.

A validação executável comprova este exemplo no ambiente registrado. Ela não substitui a demonstração geral de um algoritmo nem uma investigação empírica do problema real.
