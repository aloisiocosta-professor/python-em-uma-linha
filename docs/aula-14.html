Ordenação por partição

Como ordenar sem perder os valores repetidos?

Antes desta aula

Você vai praticar: Dividir, combinar e preservar ocorrências.

Conhecimentos anteriores: Recursão e prova por indução · Listas e compreensão

Matemática usada: Contagem e operações explicadas no exemplo.

1. Escolha uma ideia e uma pessoa para ensinar

Seu objetivo é responder à pergunta acima para alguém que nunca estudou este tema. Leia uma vez; depois esconda as explicações e reconstrua a ideia com suas palavras. Você pode ensinar em voz alta, num caderno ou no espaço abaixo. Entenda o protocolo de estudo.

2. Entenda a ideia antes do código

Escolhemos um valor de referência, separamos os menores dos demais e ordenamos cada parte antes de juntá-las.

Palavras desta aula

Pivô
Valor de referência usado para separar os demais.
Partição
Parte obtida por uma regra de separação.

Consultar o glossário. Você pode começar pelo papel: diga quais dados usaria, qual regra aplicaria e que resultado espera.

Uma comparação familiar

Organize cartões em duas mesas, os menores à esquerda e os iguais ou maiores à direita, reservando o cartão de referência.

Onde a comparação deixa de servir: A analogia não garante boa profundidade de recursão; escolhas ruins do pivô produzem divisões desequilibradas.

Ligar a ideia aos termos técnicos

Escolha o primeiro elemento como pivô; separe os menores e os demais. Ordene recursivamente ambas as partes e concatene esquerda, pivô e direita. A entrada vazia é o caso base.

Ao ensinar, explique cada termo que usar. Se um nome técnico substituir a explicação, registre-o como lacuna.

Use Python para conferir seu raciocínio

O exemplo está em uma linha física. A explicação tem o espaço necessário. Primeiro acompanhe a ideia; não é preciso decorar essa escrita. Aprender a criar e executar um arquivo.

Baixar .py
q=lambda xs:q([x for x in xs[1:] if x<xs[0]])+xs[:1]+q([x for x in xs[1:] if x>=xs[0]]) if xs else [];print(q([3,1,3,2]))

Acompanhe o mecanismo

  1. O primeiro 3 é o pivô; a esquerda recebe [1, 2] e a direita recebe [3].
  2. A esquerda vira [1, 2]; a direita já fica [3].
  3. Concatenar [1, 2], [3] e [3] produz [1, 2, 3, 3].

Antes de conferir, preveja o resultado e explique por quê. Se baixou só este arquivo, use python 14.py no terminal da pasta onde o salvou. Se obteve o repositório inteiro, use python examples/14.py na pasta principal. Use o nome de comando Python 3 identificado na preparação.

Conferir a saída esperada
[1, 2, 3, 3]

Compare também seu raciocínio com os passos acima; acertar por palpite não explica o mecanismo.

Investigar a lacuna depois de tentar
