Testes de propriedades

Um teste de exemplo compara uma entrada particular com uma resposta conhecida. Uma propriedade verifica uma relação sobre muitas entradas. Para ordenar, a sequência deve ser crescente e preservar as ocorrências.

Objetivo desta aula

Explicar testes de propriedades, prever o resultado do exemplo e modificar uma hipótese de entrada sem romper a regra de uma linha física.

Seu arquivo de uma linha

Salve como examples/26.py. A rolagem ou quebra visual na tela não muda o arquivo.

Baixar .py
from itertools import product;from collections import Counter;casos=list(product(range(3),repeat=4));print(all(Counter(sorted(x))==Counter(x) and all(a<=b for a,b in zip(sorted(x),sorted(x)[1:])) for x in casos))

Leia e execute

Leia as instruções separadas por ; da esquerda para a direita. Dentro de uma chamada, os argumentos são avaliados antes de a função ser executada. Uma compreensão percorre a fonte e aplica seu filtro antes da transformação.

No terminal: python examples/26.py. Compare o resultado com o oráculo abaixo antes de modificar o programa.

Hipóteses e limites

Uma bateria finita não prova a correção para todos os tamanhos possíveis.

A validação executável comprova este exemplo no ambiente registrado. Ela não substitui a demonstração geral de um algoritmo nem uma investigação empírica do problema real.
