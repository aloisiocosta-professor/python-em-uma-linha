Precisão e números racionais

Por que duas contas que parecem iguais podem falhar numa comparação exata?

2. Entenda a ideia antes do código

Algumas frações decimais não têm representação binária finita. O computador guarda uma aproximação; somar aproximações pode não coincidir com outra aproximação.

Palavras desta aula

Ponto flutuante
Representação finita de números, sujeita a arredondamento.
Racional
Número representável como razão de inteiros.
Tolerância
Diferença admitida por um critério de comparação.

Consultar o glossário. Você pode começar pelo papel: diga quais dados usaria, qual regra aplicaria e que resultado espera.

Uma comparação familiar

Uma régua com marcas limitadas obriga a registrar medidas entre marcas com algum arredondamento.

Onde a comparação deixa de servir: A metáfora não diz que todo decimal é impreciso em todo tipo numérico; Fraction guarda razões de inteiros exatamente.

Ligar a ideia aos termos técnicos

Números de ponto flutuante representam aproximações binárias. Fraction representa um racional exatamente como razão de inteiros. O tipo escolhido deve respeitar o significado da hipótese numérica.

Ao ensinar, explique cada termo que usar. Se um nome técnico substituir a explicação, registre-o como lacuna.

Use Python para conferir seu raciocínio

O exemplo está em uma linha física. A explicação tem o espaço necessário. Primeiro acompanhe a ideia; não é preciso decorar essa escrita. Aprender a criar e executar um arquivo.

Baixar .py
from fractions import Fraction;print(0.1+0.2==0.3,Fraction(1,10)+Fraction(2,10)==Fraction(3,10))

Acompanhe o mecanismo

  1. Os floats de 0.1 e 0.2 são aproximações; sua soma não é exatamente o float de 0.3.
  2. Fraction(1,10) e Fraction(2,10) representam razões exatas.
  3. As comparações produzem False para floats e True para as frações.
