SQL parametrizado

Uma consulta parametrizada separa o texto SQL dos valores dos dados. SQLite em memória permite experimentar sem servidor. Use placeholders para valores e um contexto para encerrar a conexão.

Objetivo desta aula

Explicar sql parametrizado, prever o resultado do exemplo e modificar uma hipótese de entrada sem romper a regra de uma linha física.

Seu arquivo de uma linha

Salve como examples/25.py. A rolagem ou quebra visual na tela não muda o arquivo.

Baixar .py
exec("import sqlite3\nfrom contextlib import closing\nwith closing(sqlite3.connect(':memory:')) as c:\n c.execute('create table t(x integer)');c.execute('insert into t values (?)',(7,));print(c.execute('select sum(x) from t').fetchone()[0])")

Leia e execute

O arquivo chama exec com uma string autoral. Dentro dela, cada \n representa uma quebra lógica e os espaços seguintes representam indentação. Leia a sequência interna de cima para baixo, como um programa convencional.

No terminal: python examples/25.py. Compare o resultado com o oráculo abaixo antes de modificar o programa.

7

Exercício

Insira também o valor 5.

Conferir resposta comentada

Repita a inserção com (5,); a soma passa a 12.

Hipóteses e limites

Placeholders não substituem identificadores de tabelas ou colunas.

A validação executável comprova este exemplo no ambiente registrado. Ela não substitui a demonstração geral de um algoritmo nem uma investigação empírica do problema real.
