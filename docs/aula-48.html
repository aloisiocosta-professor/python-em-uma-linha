2. Entenda a ideia antes do código

Escolhemos um valor inicial e aplicamos repetidamente uma transformação. Um ponto fixo é um valor que essa transformação deixa igual.

Palavras desta aula

Ponto fixo
Valor que uma transformação deixa inalterado.
Convergência
Aproximação dos termos de uma sequência a um limite.

Consultar o glossário. Você pode começar pelo papel: diga quais dados usaria, qual regra aplicaria e que resultado espera.

Uma comparação familiar

É ajustar uma peça usando repetidas correções calculadas a partir do ajuste atual.

Onde a comparação deixa de servir: Nem toda correção aproxima a resposta; convergência depende da função e da escolha inicial.

Ligar a ideia aos termos técnicos

Uma equação de ponto fixo procura x tal que g(x)=x. Iterar g constrói uma sequência de aproximações. Para raiz de 2, a iteração de Newton é g(x)=(x+2/x)/2.

Ao ensinar, explique cada termo que usar. Se um nome técnico substituir a explicação, registre-o como lacuna.

Use Python para conferir seu raciocínio

O exemplo está em uma linha física. A explicação tem o espaço necessário. Primeiro acompanhe a ideia; não é preciso decorar essa escrita. Aprender a criar e executar um arquivo.

Baixar .py
from functools import reduce;import math;x=reduce(lambda x,_:(x+2/x)/2,range(8),1.);print(math.isclose(x*x,2,abs_tol=1e-12))

Acompanhe o mecanismo

  1. Começamos em 1. A regra (x+2/x)/2 produz 1.5.
  2. A aplicação seguinte produz aproximadamente 1.4166667, mais perto da raiz positiva de 2.
  3. reduce aplica a regra oito vezes; a checagem final confirma x² próximo de 2.

Antes de conferir, preveja o resultado e explique por quê. Se baixou só este arquivo, use python 48.py no terminal da pasta onde o salvou. Se obteve o repositório inteiro, use python examples/48.py na pasta principal. Use o nome de comando Python 3 identificado na preparação.

4. Encontre uma lacuna e volte ao mecanismo

Pergunta para testar sua explicação: Por que a regra tem relação com raiz de 2?

Investigar a lacuna depois de tentar

Num ponto fixo não nulo, x=(x+2/x)/2 implica 2x=x+2/x e então x²=2.

Como reparar: Resolva a equação de ponto fixo; isso identifica candidatos, mas ainda não prova convergência. Voltar à explicação e aos passos.
