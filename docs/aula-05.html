Strings e fatiamento

Como escolher letras por posição sem reescrever a palavra?

1. Escolha uma ideia e uma pessoa para ensinar

Seu objetivo é responder à pergunta acima para alguém que nunca estudou este tema. Leia uma vez; depois esconda as explicações e reconstrua a ideia com suas palavras. Você pode ensinar em voz alta, num caderno ou no espaço abaixo. Entenda o protocolo de estudo.

2. Entenda a ideia antes do código

Uma palavra é uma sequência de caracteres. Podemos pedir um caractere, um trecho ou percorrer a sequência na direção contrária.

Uma comparação familiar

Imagine gavetas numeradas a partir de zero, cada uma com um caractere.

Onde a comparação deixa de servir: Um caractere de Python não coincide sempre com um símbolo visual completo, como certos emojis compostos.

Ligar a ideia aos termos técnicos

Sequências usam índices começando em zero. O fatiamento [início:fim:passo] exclui o limite final. O passo negativo permite percorrer uma sequência ao contrário.

Ao ensinar, explique cada termo que usar. Se um nome técnico substituir a explicação, registre-o como lacuna.

O arquivo Python continua com uma linha

Salve como examples/05.py. A explicação pode usar várias linhas; a regra de compactação vale para o arquivo Python.

Baixar .py
s='python';print(s[0],s[1:4],s[::-1])

Acompanhe o mecanismo

  1. Em python, as posições são p=0, y=1, t=2, h=3, o=4 e n=5.
  2. s[0] escolhe p; s[1:4] inclui as posições 1, 2 e 3, formando yth.
  3. s[::-1] percorre do fim para o começo, formando nohtyp.

Antes de conferir, preveja o que aparece no terminal e explique por quê. Execute com python examples/05.py.

Conferir a saída esperada
p yth nohtyp

Compare também seu raciocínio com os passos acima; acertar por palpite não explica o mecanismo.

Investigar a lacuna depois de tentar

O limite final de uma fatia é exclusivo: indica onde parar antes de incluir outra posição.
