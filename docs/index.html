Como estudar

Leia na ordem, preveja a saída, execute o arquivo e resolva o exercício antes de abrir a resposta. O formato de uma linha é sua restrição de escrita; as explicações não têm esse limite. As aulas de fronteira são introduções e exigem aprofundamento para domínio profissional.

Preparação: instale Python 3.14 e Node.js 22 ou superior. Clone o repositório; execute python -m venv .venv, .venv/bin/pip install -r requirements.txt e .venv/bin/python examples/01.py. No Windows use .venv\Scripts\python.
