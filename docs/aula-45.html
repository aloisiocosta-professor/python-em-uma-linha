Interpretador de expressões restritas

Um interpretador atribui significado aos nós de uma árvore. Aqui o domínio aceito contém apenas constantes inteiras e soma. Recusar outros nós faz parte do contrato da linguagem pequena.

Objetivo desta aula

Explicar interpretador de expressões restritas, prever o resultado do exemplo e modificar uma hipótese de entrada sem romper a regra de uma linha física.

Seu arquivo de uma linha

Salve como examples/45.py. A rolagem ou quebra visual na tela não muda o arquivo.

Baixar .py
exec("import ast\ndef valor(n):\n if isinstance(n,ast.Constant) and type(n.value) is int:return n.value\n if isinstance(n,ast.BinOp) and isinstance(n.op,ast.Add):return valor(n.left)+valor(n.right)\n raise ValueError('expressão fora da linguagem')\nprint(valor(ast.parse('2+3+4',mode='eval').body))")

Leia e execute

O arquivo chama exec com uma string autoral. Dentro dela, cada \n representa uma quebra lógica e os espaços seguintes representam indentação. Leia a sequência interna de cima para baixo, como um programa convencional.

No terminal: python examples/45.py. Compare o resultado com o oráculo abaixo antes de modificar o programa.

Exercício

O que acontece com 2*3?

Conferir resposta comentada

O interpretador lança ValueError, pois multiplicação está fora da linguagem definida.

Hipóteses e limites

Este exemplo não promete isolamento de recursos ou uma sandbox para entradas hostis.

A validação executável comprova este exemplo no ambiente registrado. Ela não substitui a demonstração geral de um algoritmo nem uma investigação empírica do problema real.
