Álgebra linear com NumPy

Um sistema linear A*x=b relaciona coeficientes, incógnitas e observações. np.linalg.solve calcula uma solução para uma matriz quadrada não singular. O residual A*x-b verifica a equação na precisão usada.

Objetivo desta aula

Explicar álgebra linear com numpy, prever o resultado do exemplo e modificar uma hipótese de entrada sem romper a regra de uma linha física.

Seu arquivo de uma linha

Salve como examples/32.py. A rolagem ou quebra visual na tela não muda o arquivo.

Baixar .py
import numpy as np;A=np.array([[2.,1.],[1.,3.]]);b=np.array([5.,5.]);x=np.linalg.solve(A,b);print(np.round(x,6).tolist(),bool(np.allclose(A@x,b)))

Leia e execute

Leia as instruções separadas por ; da esquerda para a direita. Dentro de uma chamada, os argumentos são avaliados antes de a função ser executada. Uma compreensão percorre a fonte e aplica seu filtro antes da transformação.

No terminal: python examples/32.py. Compare o resultado com o oráculo abaixo antes de modificar o programa.

[2.0, 1.0] True

Hipóteses e limites

Residual pequeno não assegura erro pequeno em sistemas mal condicionados; fonte científica N1.

A validação executável comprova este exemplo no ambiente registrado. Ela não substitui a demonstração geral de um algoritmo nem uma investigação empírica do problema real.
