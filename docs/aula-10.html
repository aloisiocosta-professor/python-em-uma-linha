Blocos em uma linha física

A gramática permite vários comandos simples separados por ;, mas não aninhamento arbitrário de comandos compostos. exec interpreta uma string como programa. Os caracteres barra invertida e n no arquivo tornam-se quebras lógicas na string.

Objetivo desta aula

Explicar blocos em uma linha física, prever o resultado do exemplo e modificar uma hipótese de entrada sem romper a regra de uma linha física.

Seu arquivo de uma linha

Salve como examples/10.py. A rolagem ou quebra visual na tela não muda o arquivo.

Baixar .py
exec("def dobro(x):\n    return x*2\nprint(dobro(5))")

Leia e execute

O arquivo chama exec com uma string autoral. Dentro dela, cada \n representa uma quebra lógica e os espaços seguintes representam indentação. Leia a sequência interna de cima para baixo, como um programa convencional.

No terminal: python examples/10.py. Compare o resultado com o oráculo abaixo antes de modificar o programa.

10

Exercício

Por que esse arquivo continua tendo uma linha física?

Conferir resposta comentada

Porque o arquivo contém a sequência escapada \n, e não a quebra física dentro do literal.

Hipóteses e limites

Use exec apenas com código autoral controlado; ele executa o conteúdo recebido.

A validação executável comprova este exemplo no ambiente registrado. Ela não substitui a demonstração geral de um algoritmo nem uma investigação empírica do problema real.
