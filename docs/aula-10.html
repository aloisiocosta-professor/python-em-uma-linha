Blocos em uma linha física

Como um programa com blocos cabe em uma linha física?

1. Escolha uma ideia e uma pessoa para ensinar

Seu objetivo é responder à pergunta acima para alguém que nunca estudou este tema. Leia uma vez; depois esconda as explicações e reconstrua a ideia com suas palavras. Você pode ensinar em voz alta, num caderno ou no espaço abaixo. Entenda o protocolo de estudo.

2. Entenda a ideia antes do código

O arquivo guarda uma string com marcas de quebra escapadas. Ao executar essa string, Python recebe linhas lógicas e indentação, mesmo que o arquivo externo tenha uma linha.

Uma comparação familiar

Um bilhete pode dizer “pule uma linha” sem já estar impresso em duas linhas.

Onde a comparação deixa de servir: exec realmente executa o texto como código. A analogia de um bilhete não oferece isolamento de execução.

Ligar a ideia aos termos técnicos

A gramática permite vários comandos simples separados por ;, mas não aninhamento arbitrário de comandos compostos. exec interpreta uma string como programa. Os caracteres barra invertida e n no arquivo tornam-se quebras lógicas na string.

Ao ensinar, explique cada termo que usar. Se um nome técnico substituir a explicação, registre-o como lacuna.

O arquivo Python continua com uma linha

Salve como examples/10.py. A explicação pode usar várias linhas; a regra de compactação vale para o arquivo Python.

Baixar .py
exec("def dobro(x):\n    return x*2\nprint(dobro(5))")

O arquivo externo chama exec com código autoral fixo. Dentro da string, \n reconstrói quebras lógicas e os espaços mantêm os blocos. A aula 10 explica essa diferença.

Acompanhe o mecanismo

  1. O literal contém a sequência escapada \n; o arquivo não ganha outra linha física ali.
  2. Ao formar a string, cada escape vira uma quebra lógica; os espaços formam o corpo de dobro.
  3. exec define dobro; dobro(5) retorna 10 e print mostra 10.

Antes de conferir, preveja o que aparece no terminal e explique por quê. Execute com python examples/10.py.

Conferir a saída esperada
10

Compare também seu raciocínio com os passos acima; acertar por palpite não explica o mecanismo.

4. Encontre uma lacuna e volte ao mecanismo

Pergunta para testar sua explicação: Uma linha física significa que não há blocos dentro do programa executado?

Investigar a lacuna depois de tentar

Não. O limite vale para a representação do arquivo; a string reconstruída ainda contém função, corpo e indentação.

Como reparar: Distingua o arquivo externo, o valor da string e o programa interpretado. Voltar à explicação e aos passos.

Se surgir outra dúvida, registre-a. Consulte o trecho correspondente ou a documentação e então esconda o material novamente. Distingua o arquivo externo, o valor da string e o programa interpretado.

Por que esse arquivo continua tendo uma linha física?

Preveja o resultado antes de executar. Depois explique o que mudou e o que permaneceu igual na regra. Se sua explicação falhar, volte ao passo 4 e registre outra revisão.

Porque o arquivo contém a sequência escapada \n, e não a quebra física dentro do literal.
