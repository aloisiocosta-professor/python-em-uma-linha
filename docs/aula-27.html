Concorrência com futures

Executor agenda chamadas e devolve os resultados de map na ordem da entrada. O contexto aguarda o encerramento dos trabalhos. O exemplo ensina a API sem depender de acesso externo.

Objetivo desta aula

Explicar concorrência com futures, prever o resultado do exemplo e modificar uma hipótese de entrada sem romper a regra de uma linha física.

Seu arquivo de uma linha

Salve como examples/27.py. A rolagem ou quebra visual na tela não muda o arquivo.

Baixar .py
exec("from concurrent.futures import ThreadPoolExecutor\nwith ThreadPoolExecutor(max_workers=2) as pool:print(list(pool.map(abs,[-2,-1,0])))")

Leia e execute

O arquivo chama exec com uma string autoral. Dentro dela, cada \n representa uma quebra lógica e os espaços seguintes representam indentação. Leia a sequência interna de cima para baixo, como um programa convencional.

No terminal: python examples/27.py. Compare o resultado com o oráculo abaixo antes de modificar o programa.

[2, 1, 0]

Exercício

A ordem da saída revela a ordem real de conclusão?

Conferir resposta comentada

Não; map preserva a ordem dos argumentos.

Hipóteses e limites

Concorrência não garante paralelismo de execução em todos os runtimes.

A validação executável comprova este exemplo no ambiente registrado. Ela não substitui a demonstração geral de um algoritmo nem uma investigação empírica do problema real.
