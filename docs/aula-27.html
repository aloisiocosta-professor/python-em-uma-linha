2. Entenda a ideia antes do código

Um executor organiza chamadas para trabalhadores disponíveis. map reúne as respostas na ordem em que os argumentos foram entregues, mesmo se terminarem em outra ordem.

Palavras desta aula

Concorrência
Organização de tarefas com períodos de progresso sobrepostos.
Executor
Componente que agenda e acompanha chamadas.
Thread
Fluxo de execução dentro de um processo.

Consultar o glossário. Você pode começar pelo papel: diga quais dados usaria, qual regra aplicaria e que resultado espera.

Uma comparação familiar

Um coordenador entrega fichas numeradas e devolve as respostas pela numeração original.

Onde a comparação deixa de servir: Ter vários trabalhadores não garante executar código Python em paralelo em qualquer ambiente.

Ligar a ideia aos termos técnicos

Executor agenda chamadas e devolve os resultados de map na ordem da entrada. O contexto aguarda o encerramento dos trabalhos. O exemplo ensina a API sem depender de acesso externo.

Ao ensinar, explique cada termo que usar. Se um nome técnico substituir a explicação, registre-o como lacuna.

Use Python para conferir seu raciocínio

O exemplo está em uma linha física. A explicação tem o espaço necessário. Primeiro acompanhe a ideia; não é preciso decorar essa escrita. Aprender a criar e executar um arquivo.

Baixar .py
exec("from concurrent.futures import ThreadPoolExecutor\nwith ThreadPoolExecutor(max_workers=2) as pool:print(list(pool.map(abs,[-2,-1,0])))")

O arquivo externo chama exec com código autoral fixo. Dentro da string, \n reconstrói quebras lógicas e os espaços mantêm os blocos. A explicação sobre blocos em uma linha mostra essa diferença.

Acompanhe o mecanismo

  1. ThreadPoolExecutor permite até dois trabalhadores.
  2. map pede abs para -2, -1 e 0; as respostas individuais são 2, 1 e 0.
  3. list recolhe os resultados na ordem das entradas; sair do with encerra o executor.

Antes de conferir, preveja o resultado e explique por quê. Se baixou só este arquivo, use python 27.py no terminal da pasta onde o salvou. Se obteve o repositório inteiro, use python examples/27.py na pasta principal. Use o nome de comando Python 3 identificado na preparação.

Conferir a saída esperada
[2, 1, 0]
