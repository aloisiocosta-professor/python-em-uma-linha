Experimento reprodutível e afirmação calibrada

Um experimento associa hipótese, dados, algoritmo, critério e ambiente. Uma semente permite registrar uma execução; um relatório deve conservar também resultados negativos. A condição abaixo valida somente um caso conhecido.

Objetivo desta aula

Explicar experimento reprodutível e afirmação calibrada, prever o resultado do exemplo e modificar uma hipótese de entrada sem romper a regra de uma linha física.

Seu arquivo de uma linha

Salve como examples/51.py. A rolagem ou quebra visual na tela não muda o arquivo.

Baixar .py
import hashlib,json;dados=[1,2,3];artefato=json.dumps(dados,separators=(',',':'));print(hashlib.sha256(artefato.encode()).hexdigest()[:12])

Leia e execute

Leia as instruções separadas por ; da esquerda para a direita. Dentro de uma chamada, os argumentos são avaliados antes de a função ser executada. Uma compreensão percorre a fonte e aplica seu filtro antes da transformação.

No terminal: python examples/51.py. Compare o resultado com o oráculo abaixo antes de modificar o programa.

a615eeaee21d

Exercício

Um hash prova que o algoritmo está correto?

Conferir resposta comentada

Não; identifica bytes do artefato. Correção requer evidência adicional, como prova ou testes adequados.

Hipóteses e limites

A conclusão deve mencionar o domínio testado e as ameaças à validade.

A validação executável comprova este exemplo no ambiente registrado. Ela não substitui a demonstração geral de um algoritmo nem uma investigação empírica do problema real.
