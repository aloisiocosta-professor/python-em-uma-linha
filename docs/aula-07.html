Dicionários, conjuntos e tuplas

Como escolher entre guardar uma ordem, uma associação e itens sem repetição?

2. Entenda a ideia antes do código

Uma sequência conserva posições. Um dicionário procura valores por chave. Um conjunto responde quais valores diferentes existem.

Uma comparação familiar

Compare uma fila de cartões, um catálogo por nome e uma coleção com um exemplar de cada selo.

Onde a comparação deixa de servir: Essas imagens não especificam todas as regras de tipos; chaves de dicionário precisam ser utilizáveis como chaves de hash.

Ligar a ideia aos termos técnicos

Um dicionário associa chaves a valores; um conjunto representa pertinência sem repetições. Tuplas agrupam valores em uma sequência imutável. Escolher a estrutura começa pelo significado dos dados.

Ao ensinar, explique cada termo que usar. Se um nome técnico substituir a explicação, registre-o como lacuna.

O arquivo Python continua com uma linha

Salve como examples/07.py. A explicação pode usar várias linhas; a regra de compactação vale para o arquivo Python.

Baixar .py
pares=[('a',1),('b',2)];d=dict(pares);print(d['b'],sorted(set([3,1,3])))

Acompanhe o mecanismo

  1. pares contém duas tuplas: a com 1 e b com 2.
  2. dict(pares) cria as associações; d["b"] encontra 2 pela chave.
  3. set retira a repetição do 3; sorted apresenta os valores diferentes como [1, 3].

Antes de conferir, preveja o que aparece no terminal e explique por quê. Execute com python examples/07.py.
