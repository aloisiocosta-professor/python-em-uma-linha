Objetos e invariantes

Uma classe reúne estado e comportamento. O construtor estabelece o estado inicial; um método deve preservar suas regras. Aqui depositar altera apenas o saldo da instância receptora.

Objetivo desta aula

Explicar objetos e invariantes, prever o resultado do exemplo e modificar uma hipótese de entrada sem romper a regra de uma linha física.

Seu arquivo de uma linha

Salve como examples/21.py. A rolagem ou quebra visual na tela não muda o arquivo.

Baixar .py
exec("class Conta:\n def __init__(self,saldo):self.saldo=saldo\n def depositar(self,v):self.saldo+=v\nc=Conta(10);c.depositar(5);print(c.saldo)")

Leia e execute

O arquivo chama exec com uma string autoral. Dentro dela, cada \n representa uma quebra lógica e os espaços seguintes representam indentação. Leia a sequência interna de cima para baixo, como um programa convencional.

No terminal: python examples/21.py. Compare o resultado com o oráculo abaixo antes de modificar o programa.

Hipóteses e limites

O exemplo não é um sistema bancário e não usa representação monetária adequada.

A validação executável comprova este exemplo no ambiente registrado. Ela não substitui a demonstração geral de um algoritmo nem uma investigação empírica do problema real.
