COMEÇAR DO ABSOLUTO ZERO

Primeiro, aprender
a pensar o problema.

Você não precisa conhecer programação, terminal ou fórmulas para iniciar. Comece com situações cotidianas, faça previsões no papel e use Python para conferir suas ideias.

O que você vai aprender

Computação estuda como representar informações e resolver problemas por processos definidos. Ciência da computação investiga princípios, algoritmos e seus limites. Engenharia de software cuida de construir, testar e manter sistemas que atendem a necessidades. Python será a ferramenta comum para explorar essas ideias.

Seu primeiro roteiro

  1. Abra O que é computar?. Leia a pergunta e tente respondê-la com um exemplo do seu dia.
  2. Use a comparação da aula e acompanhe os três passos. Nas primeiras aulas, pode apenas ler o código como uma ilustração; não precisa escrevê-lo de memória.
  3. Oculte o material e explique com suas palavras. Marque a frase em que travou, investigue e reescreva. Resolver a mesma tarefa com outro dado ajuda a conferir o raciocínio.
  4. Siga os botões de próxima aula. Eles apresentam as aulas na ordem de estudo, indicando a etapa atual e a próxima ideia.

Como saber se está pronto para continuar

Você consegue dizer qual é a pergunta, quais dados entram, qual regra se aplica e por que a saída faz sentido? Consegue inventar um caso em que a regra precisa de cuidado? Se não, volte a esse ponto específico. Não há prazo para terminar nem nota automática por preencher campos.

Vocabulário perto da dúvida

Cada aula traz “Palavras desta aula”, pré-requisitos com links e a habilidade de raciocínio praticada. O glossário reúne essas definições. A ponte matemática prepara os conceitos usados mais adiante; não é necessária para começar a primeira trilha.

Quando quiser executar Python

Um arquivo é um conteúdo guardado com nome. Um editor escreve esse conteúdo. O interpretador Python executa o programa. O terminal recebe comandos. A aula de preparação conecta essas quatro partes.

  1. Obtenha Python 3. Use a página oficial de downloads e a orientação oficial do seu sistema. Os exemplos são verificados com Python 3.14. A instalação muda entre Windows, macOS, Linux e celulares; não é preciso instalar nada para fazer as primeiras atividades no papel.
  2. Crie uma pasta de estudo. Uma pasta organiza arquivos. Nela, use um editor de texto simples para salvar primeiro.py com uma linha: print('Estou aprendendo'). Evite um editor que salve formatação de documento; confira que o nome não terminou em .py.txt.
  3. Abra o terminal nessa pasta. O sistema pode oferecer essa opção no gerenciador de arquivos. O comando cd muda a pasta corrente: cd "caminho da sua pasta", substituindo o texto pelo caminho real. Não digite essa frase como se fosse um caminho universal.
  4. Confira o interpretador. Digite python --version. Se o sistema usar outro nome, tente python3 --version; no Windows pode existir py --version. O comando escolhido deve indicar Python 3.
  5. Execute. Use o mesmo nome de comando seguido do arquivo: python primeiro.py, python3 primeiro.py ou py primeiro.py. O terminal deve mostrar Estou aprendendo.

Se a instalação trouxe o editor IDLE, você também pode abrir o arquivo nele e escolher executar o módulo pelo menu Run. A documentação de IDLE descreve essa interface.

Se aparecer um erro

  • Comando não encontrado: o sistema ainda não encontra esse interpretador; confira a instalação e o nome do comando.
  • Arquivo não encontrado: confira pasta atual, nome e extensão.
  • SyntaxError: Python não conseguiu interpretar a escrita; compare aspas, parênteses e caracteres com o exemplo.
  • Nome não definido: confira se um texto perdeu as aspas ou se um nome foi escrito de outro modo.

O que instalar agora e o que deixar para depois

As primeiras trilhas usam apenas o que vem com Python. Node.js e Git são ferramentas de manutenção da wiki e não são necessários para estudar uma aula. A trilha científica usa bibliotecas adicionais; sua preparação aparece abaixo, quando fizer sentido.

Preparar bibliotecas para a trilha científica

Um pacote acrescenta ferramentas ao Python. Um ambiente virtual separa os pacotes deste projeto dos demais. O arquivo requirements.txt lista as versões usadas nos testes.

  1. Obtenha os arquivos pelo botão Code → Download ZIP do repositório, extraia a pasta e abra seu terminal nela.
  2. Com o interpretador escolhido, execute python -m venv .venv. O argumento -m pede execução de um módulo; venv cria o ambiente na pasta .venv. Troque python pelo comando encontrado no seu sistema.
  3. No Linux/macOS, use .venv/bin/python -m pip install -r requirements.txt. No Windows, use .venv\Scripts\python.exe -m pip install -r requirements.txt. pip instala os pacotes listados.
  4. Execute o exemplo científico com esse Python do ambiente; por exemplo .venv/bin/python examples/32.py no Linux/macOS.
