Programação dinâmica

Subproblemas sobrepostos podem ter suas respostas guardadas. O cache memoriza chamadas por argumentos. Fibonacci tem f(0)=0, f(1)=1 e f(n)=f(n-1)+f(n-2).

Objetivo desta aula

Explicar programação dinâmica, prever o resultado do exemplo e modificar uma hipótese de entrada sem romper a regra de uma linha física.

Seu arquivo de uma linha

Salve como examples/18.py. A rolagem ou quebra visual na tela não muda o arquivo.

Baixar .py
exec("from functools import cache\n@cache\ndef fib(n):return n if n<2 else fib(n-1)+fib(n-2)\nprint(fib(20))")

Leia e execute

O arquivo chama exec com uma string autoral. Dentro dela, cada \n representa uma quebra lógica e os espaços seguintes representam indentação. Leia a sequência interna de cima para baixo, como um programa convencional.

No terminal: python examples/18.py. Compare o resultado com o oráculo abaixo antes de modificar o programa.

Exercício

Qual o efeito de remover @cache?

Conferir resposta comentada

O resultado matemático permanece; subproblemas voltam a ser recalculados.

Hipóteses e limites

O domínio adotado é inteiro não negativo e ainda existe limite de profundidade recursiva.

A validação executável comprova este exemplo no ambiente registrado. Ela não substitui a demonstração geral de um algoritmo nem uma investigação empírica do problema real.
