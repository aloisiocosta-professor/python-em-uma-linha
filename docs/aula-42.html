Protocolos e operadores

Métodos especiais permitem que objetos participem de operações da linguagem. __add__ recebe o outro operando. O exemplo define soma em um espaço vetorial de duas coordenadas.

Objetivo desta aula

Explicar protocolos e operadores, prever o resultado do exemplo e modificar uma hipótese de entrada sem romper a regra de uma linha física.

Seu arquivo de uma linha

Salve como examples/42.py. A rolagem ou quebra visual na tela não muda o arquivo.

Leia e execute

O arquivo chama exec com uma string autoral. Dentro dela, cada \n representa uma quebra lógica e os espaços seguintes representam indentação. Leia a sequência interna de cima para baixo, como um programa convencional.

Hipóteses e limites

Compatibilidade de tipos e NotImplemented precisam ser tratados em uma biblioteca.

A validação executável comprova este exemplo no ambiente registrado. Ela não substitui a demonstração geral de um algoritmo nem uma investigação empírica do problema real.
