Equações diferenciais

Uma EDO descreve uma taxa de variação. Para y'=−y e y(0)=1, a solução analítica é exp(−t). Comparar a integração numérica com essa solução fornece um oráculo independente.

Objetivo desta aula

Explicar equações diferenciais, prever o resultado do exemplo e modificar uma hipótese de entrada sem romper a regra de uma linha física.

Seu arquivo de uma linha

Salve como examples/36.py. A rolagem ou quebra visual na tela não muda o arquivo.

Baixar .py
from scipy.integrate import solve_ivp;import math;r=solve_ivp(lambda t,y:-y,(0,1),[1.],rtol=1e-9,atol=1e-12);print(r.success,math.isclose(r.y[0,-1],math.exp(-1),rel_tol=1e-7))

Leia e execute

Leia as instruções separadas por ; da esquerda para a direita. Dentro de uma chamada, os argumentos são avaliados antes de a função ser executada. Uma compreensão percorre a fonte e aplica seu filtro antes da transformação.

Exercício

Qual é a solução com y(0)=2?

Conferir resposta comentada

2*exp(-t), pois a equação é linear e homogênea.

Hipóteses e limites

Um caso com solução conhecida não valida todos os regimes de uma EDO.

A validação executável comprova este exemplo no ambiente registrado. Ela não substitui a demonstração geral de um algoritmo nem uma investigação empírica do problema real.
