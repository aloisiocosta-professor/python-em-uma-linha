Ligar a ideia aos termos técnicos

Uma EDO descreve uma taxa de variação. Para y'=−y e y(0)=1, a solução analítica é exp(−t). Comparar a integração numérica com essa solução fornece um oráculo independente.

Ao ensinar, explique cada termo que usar. Se um nome técnico substituir a explicação, registre-o como lacuna.

O arquivo Python continua com uma linha

Salve como examples/36.py. A explicação pode usar várias linhas; a regra de compactação vale para o arquivo Python.

Baixar .py
from scipy.integrate import solve_ivp;import math;r=solve_ivp(lambda t,y:-y,(0,1),[1.],rtol=1e-9,atol=1e-12);print(r.success,math.isclose(r.y[0,-1],math.exp(-1),rel_tol=1e-7))

Acompanhe o mecanismo

  1. A regra y'=−y diz que a taxa é negativa e tem o tamanho do estado atual.
  2. Com y(0)=1, a trajetória conhecida é exp(-t); em t=1 vale exp(-1).
  3. solve_ivp integra a regra; verificamos tanto o sucesso informado quanto a proximidade com exp(-1).
