2. Entenda a ideia antes do código

O modelo aprende com o treino. Transformações que aprendem estatísticas dos dados também devem ser ajustadas só no treino.

Palavras desta aula

Treino
Dados usados para ajustar o modelo e suas transformações.
Teste
Dados reservados à avaliação.
Vazamento
Uso indevido de informação reservada durante o ajuste.
Pipeline
Composição de transformações e estimador numa sequência.

Consultar o glossário. Você pode começar pelo papel: diga quais dados usaria, qual regra aplicaria e que resultado espera.

Uma comparação familiar

Uma prova deixa de avaliar o que foi aprendido se suas respostas participam da preparação do aluno.

Onde a comparação deixa de servir: O exemplo usa apenas dois pontos sintéticos para demonstrar a API; isso não constitui uma avaliação robusta de generalização.

Ligar a ideia aos termos técnicos

Separe observações de treino e teste antes de ajustar transformações. Pipeline combina padronização e classificador; fit recebe só o treino. A avaliação abaixo usa dados sintéticos finitos, não uma população real.

Ao ensinar, explique cada termo que usar. Se um nome técnico substituir a explicação, registre-o como lacuna.

Use Python para conferir seu raciocínio

O exemplo está em uma linha física. A explicação tem o espaço necessário. Primeiro acompanhe a ideia; não é preciso decorar essa escrita. Aprender a criar e executar um arquivo.

Baixar .py
from sklearn.pipeline import make_pipeline;from sklearn.preprocessing import StandardScaler;from sklearn.linear_model import LogisticRegression;X=[[0],[1],[2],[8],[9],[10]];y=[0,0,0,1,1,1];m=make_pipeline(StandardScaler(),LogisticRegression()).fit(X,y);print(m.predict([[1.5],[8.5]]).tolist())

Acompanhe o mecanismo

  1. X e y fornecem seis observações de treino e suas classes.
  2. Pipeline ajusta a padronização e a regressão logística usando somente esse treino.
  3. predict transforma os novos pontos com a regra aprendida e produz [0,1], sem ajustar novamente o modelo.

Antes de conferir, preveja o resultado e explique por quê. Se baixou só este arquivo, use python 39.py no terminal da pasta onde o salvou. Se obteve o repositório inteiro, use python examples/39.py na pasta principal. Use o nome de comando Python 3 identificado na preparação.
