04 · Computação científica / AULA 39

Aprendizado de máquina sem vazamento

Separe observações de treino e teste antes de ajustar transformações. Pipeline combina padronização e classificador; fit recebe só o treino. A avaliação abaixo usa dados sintéticos finitos, não uma população real.

Objetivo desta aula

Explicar aprendizado de máquina sem vazamento, prever o resultado do exemplo e modificar uma hipótese de entrada sem romper a regra de uma linha física.

Seu arquivo de uma linha

Salve como examples/39.py. A rolagem ou quebra visual na tela não muda o arquivo.

Baixar .py
from sklearn.pipeline import make_pipeline;from sklearn.preprocessing import StandardScaler;from sklearn.linear_model import LogisticRegression;X=[[0],[1],[2],[8],[9],[10]];y=[0,0,0,1,1,1];m=make_pipeline(StandardScaler(),LogisticRegression()).fit(X,y);print(m.predict([[1.5],[8.5]]).tolist())

Leia e execute

Leia as instruções separadas por ; da esquerda para a direita. Dentro de uma chamada, os argumentos são avaliados antes de a função ser executada. Uma compreensão percorre a fonte e aplica seu filtro antes da transformação.

No terminal: python examples/39.py. Compare o resultado com o oráculo abaixo antes de modificar o programa.
