O que é computar?

O que acontece entre fazer uma pergunta e receber uma resposta de um computador?

Antes desta aula

Você vai praticar: Separar a pergunta da regra que a resolve.

Conhecimentos anteriores: Nenhum conhecimento de computação. Comece com uma pergunta do seu cotidiano.

Matemática usada: Somente contagem e contas apresentadas no exemplo.

1. Escolha uma ideia e uma pessoa para ensinar

Seu objetivo é responder à pergunta acima para alguém que nunca estudou este tema. Leia uma vez; depois esconda as explicações e reconstrua a ideia com suas palavras. Você pode ensinar em voz alta, num caderno ou no espaço abaixo. Entenda o protocolo de estudo.

2. Entenda a ideia antes do código

Computar é transformar informações seguindo regras. Um computador executa instruções sobre dados. Python é uma linguagem em que escrevemos essas instruções; ainda não precisamos saber escrevê-las para acompanhar uma conta.

Palavras desta aula

Dado
Informação escolhida para representar algo.
Instrução
Uma ordem que descreve uma ação.
Python
Linguagem usada para escrever programas.

Consultar o glossário. Você pode começar pelo papel: diga quais dados usaria, qual regra aplicaria e que resultado espera.

Uma comparação familiar

Uma calculadora recebe uma conta e mostra seu resultado.

Onde a comparação deixa de servir: Uma máquina segue o programa e suas entradas; ela não garante que escolhemos a pergunta ou a regra correta.

Ligar a ideia aos termos técnicos

Ao ensinar, explique cada termo que usar. Se um nome técnico substituir a explicação, registre-o como lacuna.

Use Python para conferir seu raciocínio

O exemplo está em uma linha física. A explicação tem o espaço necessário. Primeiro acompanhe a ideia; não é preciso decorar essa escrita. Aprender a criar e executar um arquivo.

Baixar .py
print(2+3)

Acompanhe o mecanismo

  1. Temos dois grupos: um com 2 itens e outro com 3.
  2. A regra de juntar as quantidades é a soma: 2+3.
  3. O exemplo pede a Python que mostre o resultado; print significa mostrar e a resposta é 5.

Antes de conferir, preveja o resultado e explique por quê. Se baixou só este arquivo, use python z01.py no terminal da pasta onde o salvou. Se obteve o repositório inteiro, use python examples/z01.py na pasta principal. Use o nome de comando Python 3 identificado na preparação.

Conferir a saída esperada
5

Compare também seu raciocínio com os passos acima; acertar por palpite não explica o mecanismo.

3. Ensine sem consultar

Explique para um iniciante: O que acontece entre fazer uma pergunta e receber uma resposta de um computador? Use um exemplo seu, acompanhe uma mudança de estado ou valor e explique por que ela ocorre. Não copie a explicação acima.

Sua primeira explicação

Diga o que entra, o que acontece e por que a saída faz sentido. Se travar, escreva o ponto exato.

4. Encontre uma lacuna e volte ao mecanismo

Pergunta para testar sua explicação: Se o resultado é 5, isso prova que juntar era a operação certa para qualquer problema?

Investigar a lacuna depois de tentar

Não. A conta está correta, mas o problema poderia pedir outra coisa, como a diferença entre os grupos.

Como reparar: Volte aos três passos desta aula, refaça o exemplo no papel e explique qual regra responde à dúvida. Voltar à explicação e aos passos.

Se surgir outra dúvida, registre-a. Consulte o trecho correspondente ou a documentação e então esconda o material novamente. Volte aos três passos desta aula, refaça o exemplo no papel e explique qual regra responde à dúvida.

6. Teste sua explicação em outro caso

Invente uma pergunta em que 2 e 3 sejam dados, mas a resposta não seja 5.

Preveja o resultado antes de executar. Depois explique o que mudou e o que permaneceu igual na regra. Se sua explicação falhar, volte ao passo 4 e registre outra revisão.
