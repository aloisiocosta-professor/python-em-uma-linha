Corrotinas e asyncio

Como alternar tarefas enquanto elas aguardam alguma coisa?

1. Escolha uma ideia e uma pessoa para ensinar

Seu objetivo é responder à pergunta acima para alguém que nunca estudou este tema. Leia uma vez; depois esconda as explicações e reconstrua a ideia com suas palavras. Você pode ensinar em voz alta, num caderno ou no espaço abaixo. Entenda o protocolo de estudo.

2. Entenda a ideia antes do código

Uma corrotina pode ceder o controle durante uma espera. O ciclo de eventos continua outras tarefas prontas e depois retoma a que esperava.

Uma comparação familiar

Um cozinheiro põe água para ferver e prepara outro ingrediente enquanto aguarda.

Onde a comparação deixa de servir: O cozinheiro da analogia não é uma thread por panela; asyncio depende de pontos cooperativos de espera.

Ligar a ideia aos termos técnicos

async def define uma função que produz uma corrotina. await permite aguardar outra operação cooperativamente. gather reúne resultados das corrotinas na ordem em que foram fornecidas.

Ao ensinar, explique cada termo que usar. Se um nome técnico substituir a explicação, registre-o como lacuna.

O arquivo Python continua com uma linha

Salve como examples/28.py. A explicação pode usar várias linhas; a regra de compactação vale para o arquivo Python.

Baixar .py
exec("import asyncio\nasync def tarefa(x):\n await asyncio.sleep(0)\n return x*x\nasync def main():print(await asyncio.gather(tarefa(2),tarefa(3)))\nasyncio.run(main())")

O arquivo externo chama exec com código autoral fixo. Dentro da string, \n reconstrói quebras lógicas e os espaços mantêm os blocos. A aula 10 explica essa diferença.

Acompanhe o mecanismo

  1. asyncio.run inicia main; gather recebe tarefa(2) e tarefa(3).
  2. Cada tarefa faz await sleep(0), oferecendo uma oportunidade de alternar a execução.
  3. As tarefas devolvem 4 e 9; gather os reúne na ordem fornecida e main imprime [4, 9].

Antes de conferir, preveja o que aparece no terminal e explique por quê. Execute com python examples/28.py.

Conferir a saída esperada
