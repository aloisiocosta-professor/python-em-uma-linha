Corrotinas e asyncio

async def define uma função que produz uma corrotina. await permite aguardar outra operação cooperativamente. gather reúne resultados das corrotinas na ordem em que foram fornecidas.

Objetivo desta aula

Explicar corrotinas e asyncio, prever o resultado do exemplo e modificar uma hipótese de entrada sem romper a regra de uma linha física.

Seu arquivo de uma linha

Salve como examples/28.py. A rolagem ou quebra visual na tela não muda o arquivo.

Baixar .py
exec("import asyncio\nasync def tarefa(x):\n await asyncio.sleep(0)\n return x*x\nasync def main():print(await asyncio.gather(tarefa(2),tarefa(3)))\nasyncio.run(main())")

Leia e execute

O arquivo chama exec com uma string autoral. Dentro dela, cada \n representa uma quebra lógica e os espaços seguintes representam indentação. Leia a sequência interna de cima para baixo, como um programa convencional.

No terminal: python examples/28.py. Compare o resultado com o oráculo abaixo antes de modificar o programa.

[4, 9]

Exercício

Por que await não pode ficar livre no topo deste arquivo?

Conferir resposta comentada

Um arquivo Python normal exige await dentro de uma função assíncrona; asyncio.run inicia o ciclo de eventos.

Hipóteses e limites

Operações bloqueantes dentro de uma corrotina podem bloquear o ciclo de eventos.

A validação executável comprova este exemplo no ambiente registrado. Ela não substitui a demonstração geral de um algoritmo nem uma investigação empírica do problema real.
