Broadcasting e eixos

Arrays representam dados por forma e eixos. Broadcasting combina dimensões compatíveis. A média por eixo produz uma referência para centralizar as colunas de uma tabela.

Objetivo desta aula

Explicar broadcasting e eixos, prever o resultado do exemplo e modificar uma hipótese de entrada sem romper a regra de uma linha física.

Seu arquivo de uma linha

Salve como examples/33.py. A rolagem ou quebra visual na tela não muda o arquivo.

Baixar .py
import numpy as np;X=np.array([[1.,2.],[3.,4.]]);print((X-X.mean(axis=0)).tolist())

Leia e execute

Leia as instruções separadas por ; da esquerda para a direita. Dentro de uma chamada, os argumentos são avaliados antes de a função ser executada. Uma compreensão percorre a fonte e aplica seu filtro antes da transformação.

No terminal: python examples/33.py. Compare o resultado com o oráculo abaixo antes de modificar o programa.

[[-1.0, -1.0], [1.0, 1.0]]

Exercício

O que muda com axis=1 e keepdims=True?

Conferir resposta comentada
