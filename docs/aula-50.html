Modelo mínimo de verificação formal

Uma propriedade de segurança exclui estados ruins alcançáveis. Enumerar todas as execuções de comprimento fixo é uma exploração limitada do espaço de estados. Uma violação fornece um contraexemplo.

Objetivo desta aula

Explicar modelo mínimo de verificação formal, prever o resultado do exemplo e modificar uma hipótese de entrada sem romper a regra de uma linha física.

Seu arquivo de uma linha

Salve como examples/50.py. A rolagem ou quebra visual na tela não muda o arquivo.

Baixar .py
from itertools import product;trilhas=list(product([-1,1],repeat=3));ruins=[t for t in trilhas if any(sum(t[:k])<0 for k in range(1,4))];print(len(trilhas),bool(ruins))

Leia e execute

Leia as instruções separadas por ; da esquerda para a direita. Dentro de uma chamada, os argumentos são avaliados antes de a função ser executada. Uma compreensão percorre a fonte e aplica seu filtro antes da transformação.

No terminal: python examples/50.py. Compare o resultado com o oráculo abaixo antes de modificar o programa.

8 True

Exercício

Qual contraexemplo já viola a propriedade no primeiro passo?

Conferir resposta comentada

Qualquer trilha que comece com -1 leva o contador inicial zero a um estado negativo.

Hipóteses e limites

Limite de três passos; ausência de falha nesse limite não provaria segurança ilimitada.

A validação executável comprova este exemplo no ambiente registrado. Ela não substitui a demonstração geral de um algoritmo nem uma investigação empírica do problema real.
