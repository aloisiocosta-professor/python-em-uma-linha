Exceções e contratos

Uma exceção distingue falha de um resultado normal. try delimita a operação e except trata uma classe específica de falha. Capturar apenas o que se sabe tratar preserva informação sobre erros inesperados.

Objetivo desta aula

Explicar exceções e contratos, prever o resultado do exemplo e modificar uma hipótese de entrada sem romper a regra de uma linha física.

Seu arquivo de uma linha

Salve como examples/22.py. A rolagem ou quebra visual na tela não muda o arquivo.

Baixar .py
exec("try:\n int('x')\nexcept ValueError:\n print('entrada inválida')")

Leia e execute

O arquivo chama exec com uma string autoral. Dentro dela, cada \n representa uma quebra lógica e os espaços seguintes representam indentação. Leia a sequência interna de cima para baixo, como um programa convencional.

No terminal: python examples/22.py. Compare o resultado com o oráculo abaixo antes de modificar o programa.

entrada inválida

Hipóteses e limites

Um contrato precisa especificar também o comportamento esperado em caso de sucesso.

A validação executável comprova este exemplo no ambiente registrado. Ela não substitui a demonstração geral de um algoritmo nem uma investigação empírica do problema real.
