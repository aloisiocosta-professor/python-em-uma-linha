Exceções e contratos

Como tratar uma entrada inválida sem confundi-la com um resultado?

1. Escolha uma ideia e uma pessoa para ensinar

Seu objetivo é responder à pergunta acima para alguém que nunca estudou este tema. Leia uma vez; depois esconda as explicações e reconstrua a ideia com suas palavras. Você pode ensinar em voz alta, num caderno ou no espaço abaixo. Entenda o protocolo de estudo.

2. Entenda a ideia antes do código

Tentamos uma operação. Se ela falha de um modo conhecido, desviamos para um tratamento específico.

Uma comparação familiar

Um formulário pode encaminhar um campo ilegível para revisão em vez de inventar um número.

Onde a comparação deixa de servir: Uma exceção não é simplesmente uma mensagem: ela muda o fluxo e pode se propagar se ninguém a tratar.

Ligar a ideia aos termos técnicos

Uma exceção distingue falha de um resultado normal. try delimita a operação e except trata uma classe específica de falha. Capturar apenas o que se sabe tratar preserva informação sobre erros inesperados.

Ao ensinar, explique cada termo que usar. Se um nome técnico substituir a explicação, registre-o como lacuna.

O arquivo Python continua com uma linha

Salve como examples/22.py. A explicação pode usar várias linhas; a regra de compactação vale para o arquivo Python.

Baixar .py
exec("try:\n int('x')\nexcept ValueError:\n print('entrada inválida')")

O arquivo externo chama exec com código autoral fixo. Dentro da string, \n reconstrói quebras lógicas e os espaços mantêm os blocos. A aula 10 explica essa diferença.

Acompanhe o mecanismo

  1. try inicia a tentativa de converter x para inteiro.
  2. int não aceita essa representação e lança ValueError.
  3. except ValueError recebe essa falha e imprime entrada inválida.

Antes de conferir, preveja o que aparece no terminal e explique por quê. Execute com python examples/22.py.
