Cálculo simbólico

Uma expressão simbólica conserva relações algébricas antes da aproximação numérica. diff deriva uma expressão em relação a um símbolo. Isso permite comparar uma derivada formal com uma implementação numérica.

Objetivo desta aula

Explicar cálculo simbólico, prever o resultado do exemplo e modificar uma hipótese de entrada sem romper a regra de uma linha física.

Seu arquivo de uma linha

Salve como examples/37.py. A rolagem ou quebra visual na tela não muda o arquivo.

Baixar .py
import sympy as s;x=s.symbols('x');print(s.diff(x**3+2*x,x))

Leia e execute

Leia as instruções separadas por ; da esquerda para a direita. Dentro de uma chamada, os argumentos são avaliados antes de a função ser executada. Uma compreensão percorre a fonte e aplica seu filtro antes da transformação.

No terminal: python examples/37.py. Compare o resultado com o oráculo abaixo antes de modificar o programa.

3*x**2 + 2

Hipóteses e limites

A validação executável comprova este exemplo no ambiente registrado. Ela não substitui a demonstração geral de um algoritmo nem uma investigação empírica do problema real.
