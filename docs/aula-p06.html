2. Entenda a ideia antes do código

Arquitetura de software decide quais partes existem, suas responsabilidades e como se comunicam. Aqui uma parte coordena o pedido, outra valida, outra calcula e outra apresenta.

Palavras desta aula

Arquitetura
Organização das partes maiores, responsabilidades e comunicação de um sistema.
Validação
Conferência de que uma entrada atende a regras.
Camada
Grupo de responsabilidades com uma fronteira definida.

Use Python para conferir seu raciocínio

O exemplo está em uma linha física. A explicação tem o espaço necessário. Primeiro acompanhe a ideia; não é preciso decorar essa escrita. Aprender a criar e executar um arquivo.

Baixar .py
validar=lambda n:n>=0;calcular=lambda n:n*4;apresentar=lambda n:f'Total: {n}';pedido=lambda n:apresentar(calcular(n)) if validar(n) else 'Quantidade invalida';print(pedido(2))

Acompanhe o mecanismo

  1. pedido recebe 2 e chama validar; 2>=0 permite continuar.
  2. calcular recebe 2 e devolve 8.
  3. apresentar transforma 8 em Total: 8; pedido devolve esse texto e print o exibe.

Antes de conferir, preveja o resultado e explique por quê. Se baixou só este arquivo, use python p06.py no terminal da pasta onde o salvou. Se obteve o repositório inteiro, use python examples/p06.py na pasta principal. Use o nome de comando Python 3 identificado na preparação.
