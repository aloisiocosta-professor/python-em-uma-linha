2. Entenda a ideia antes do código

Um gerador entrega valores à medida que alguém os pede. Depois de entregar todos, ele fica esgotado; não volta sozinho ao começo.

Palavras desta aula

Iterador
Objeto que entrega próximos valores e mantém seu estado de percurso.
Gerador
Tipo de iterador que pode produzir valores sob demanda.

Consultar o glossário. Você pode começar pelo papel: diga quais dados usaria, qual regra aplicaria e que resultado espera.

Uma comparação familiar

É uma fila de senhas descartáveis: retirar todas não cria novas senhas para a próxima pessoa.

Onde a comparação deixa de servir: O gerador calcula valores ao ser consumido; eles não precisam estar todos prontos numa fila real.

Ligar a ideia aos termos técnicos

Uma expressão geradora produz valores sob demanda. sum consome o iterador até o fim. Um iterador consumido não reinicia automaticamente: isso faz parte do seu estado.

Ao ensinar, explique cada termo que usar. Se um nome técnico substituir a explicação, registre-o como lacuna.

Use Python para conferir seu raciocínio

O exemplo está em uma linha física. A explicação tem o espaço necessário. Primeiro acompanhe a ideia; não é preciso decorar essa escrita. Aprender a criar e executar um arquivo.

Baixar .py
g=(x*x for x in range(4));print(sum(g),list(g))

Acompanhe o mecanismo

  1. g prepara os quadrados de 0, 1, 2 e 3.
  2. sum pede todos: 0+1+4+9=14 e esgota g.
  3. list(g) pede o que restou; não há valores, então recebe [].

Antes de conferir, preveja o resultado e explique por quê. Se baixou só este arquivo, use python 09.py no terminal da pasta onde o salvou. Se obteve o repositório inteiro, use python examples/09.py na pasta principal. Use o nome de comando Python 3 identificado na preparação.

Conferir a saída esperada
14 []

Investigar a lacuna depois de tentar

A variável referencia o gerador com seu estado de consumo; não uma lista com a história dos valores entregues.

Como reparar: Contraste o gerador com uma lista materializada antes de sum. Voltar à explicação e aos passos.
