2. Entenda a ideia antes do código

Uma interface define o modo de usar uma parte: quais informações ela recebe e o que promete devolver. Partes compatíveis com esse acordo podem ser substituídas.

Palavras desta aula

Interface
Acordo sobre como uma parte pode ser usada.
Dependência
Parte ou informação necessária para outra funcionar.

Consultar o glossário. Você pode começar pelo papel: diga quais dados usaria, qual regra aplicaria e que resultado espera.

Use Python para conferir seu raciocínio

O exemplo está em uma linha física. A explicação tem o espaço necessário. Primeiro acompanhe a ideia; não é preciso decorar essa escrita. Aprender a criar e executar um arquivo.

Baixar .py
aplicar=lambda operacao,x:operacao(x);print(aplicar(lambda n:n+1,4))

Acompanhe o mecanismo

  1. aplicar recebe uma operação e um valor.
  2. A operação fornecida recebe um número e devolve esse número mais 1.
  3. Com x=4, aplicar devolve 5 sem precisar conhecer como a operação foi construída.

Antes de conferir, preveja o resultado e explique por quê. Se baixou só este arquivo, use python p05.py no terminal da pasta onde o salvou. Se obteve o repositório inteiro, use python examples/p05.py na pasta principal. Use o nome de comando Python 3 identificado na preparação.

Conferir a saída esperada
5
