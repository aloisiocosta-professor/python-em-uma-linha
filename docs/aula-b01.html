Repetir ações com for

Como aplicar a mesma ação a vários valores?

Use Python para conferir seu raciocínio

O exemplo está em uma linha física. A explicação tem o espaço necessário. Primeiro acompanhe a ideia; não é preciso decorar essa escrita. Aprender a criar e executar um arquivo.

Baixar .py
exec("for numero in [1,2,3]:\n print(numero*2)")

O arquivo externo chama exec com código autoral fixo. Dentro da string, \n reconstrói quebras lógicas e os espaços mantêm os blocos. A explicação sobre blocos em uma linha mostra essa diferença.

Acompanhe o mecanismo

  1. numero recebe 1; multiplicar por 2 produz e imprime 2.
  2. Na passagem seguinte recebe 2 e imprime 4.
  3. Na última recebe 3 e imprime 6; não há mais valores e o laço termina.

Antes de conferir, preveja o resultado e explique por quê. Se baixou só este arquivo, use python b01.py no terminal da pasta onde o salvou. Se obteve o repositório inteiro, use python examples/b01.py na pasta principal. Use o nome de comando Python 3 identificado na preparação.

Conferir a saída esperada
2
4
6

Compare também seu raciocínio com os passos acima; acertar por palpite não explica o mecanismo.

4. Encontre uma lacuna e volte ao mecanismo

Pergunta para testar sua explicação: A variável numero guarda todos os valores de uma vez?

Investigar a lacuna depois de tentar

Não. A cada passagem ela referencia o valor corrente fornecido pela fonte.
