Union-find e componentes

Cada conjunto possui um representante. find segue os pais até uma raiz; unir dois conjuntos altera o pai de uma raiz. A igualdade de representantes responde conectividade.

Objetivo desta aula

Explicar union-find e componentes, prever o resultado do exemplo e modificar uma hipótese de entrada sem romper a regra de uma linha física.

Seu arquivo de uma linha

Salve como examples/19.py. A rolagem ou quebra visual na tela não muda o arquivo.

Baixar .py
exec("p=list(range(4))\ndef find(x):\n while p[x]!=x:x=p[x]\n return x\np[find(1)]=find(0)\np[find(2)]=find(1)\nprint(find(0)==find(2),find(0)==find(3))")

Leia e execute

O arquivo chama exec com uma string autoral. Dentro dela, cada \n representa uma quebra lógica e os espaços seguintes representam indentação. Leia a sequência interna de cima para baixo, como um programa convencional.

No terminal: python examples/19.py. Compare o resultado com o oráculo abaixo antes de modificar o programa.

True False

Exercício

Una o vértice 3 ao conjunto de 2.

Conferir resposta comentada

Execute p[find(3)]=find(2); todos os quatro ficam conectados.

Hipóteses e limites

A versão mostra a semântica básica; compressão de caminhos é uma extensão.

A validação executável comprova este exemplo no ambiente registrado. Ela não substitui a demonstração geral de um algoritmo nem uma investigação empírica do problema real.
