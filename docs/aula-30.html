2. Entenda a ideia antes do código

Cada evento carrega um vetor de contagens conhecidas por processo. Comparamos todas as posições para ver se um registro está inteiramente contido no outro.

Palavras desta aula

Vetor
Sequência de componentes comparadas por posição neste modelo.
Causalidade
Relação de dependência entre eventos.
Eventos concorrentes
Eventos sem precedência causal entre si no modelo.

Consultar o glossário. Você pode começar pelo papel: diga quais dados usaria, qual regra aplicaria e que resultado espera.

Uma comparação familiar

Duas pessoas mantêm listas do que cada uma já recebeu; listas que avançam em lados diferentes não dizem que uma recebeu tudo da outra.

Onde a comparação deixa de servir: Os vetores só representam causalidade quando são mantidos pelo protocolo correto; números arbitrários não criam uma história causal.

Ligar a ideia aos termos técnicos

Um vetor resume o conhecimento causal de eventos em processos. A precede B se todas as coordenadas de A são menores ou iguais e pelo menos uma é estritamente menor. Vetores incomparáveis representam eventos concorrentes no modelo.

Ao ensinar, explique cada termo que usar. Se um nome técnico substituir a explicação, registre-o como lacuna.

Use Python para conferir seu raciocínio

O exemplo está em uma linha física. A explicação tem o espaço necessário. Primeiro acompanhe a ideia; não é preciso decorar essa escrita. Aprender a criar e executar um arquivo.

Baixar .py
antes=lambda a,b:all(x<=y for x,y in zip(a,b)) and any(x<y for x,y in zip(a,b));a=(1,0);b=(0,1);print(antes(a,b),antes(b,a))

Acompanhe o mecanismo

  1. a=(1,0) tem mais informação na primeira posição; b=(0,1) tem mais na segunda.
  2. Para antes(a,b), 1<=0 falha; para antes(b,a), a outra coordenada falha.
  3. As duas comparações são False: os registros são incomparáveis neste modelo.

Antes de conferir, preveja o resultado e explique por quê. Se baixou só este arquivo, use python 30.py no terminal da pasta onde o salvou. Se obteve o repositório inteiro, use python examples/30.py na pasta principal. Use o nome de comando Python 3 identificado na preparação.
