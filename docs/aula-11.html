Recursão e prova por indução

Como uma função resolve um problema pedindo ajuda a uma versão menor dele?

1. Escolha uma ideia e uma pessoa para ensinar

Seu objetivo é responder à pergunta acima para alguém que nunca estudou este tema. Leia uma vez; depois esconda as explicações e reconstrua a ideia com suas palavras. Você pode ensinar em voz alta, num caderno ou no espaço abaixo. Entenda o protocolo de estudo.

2. Entenda a ideia antes do código

Para calcular n!, multiplicamos n pelo fatorial anterior. Quando chegamos a zero, devolvemos 1 sem pedir outra ajuda.

Uma comparação familiar

Uma pessoa pede a outra a resposta de uma tarefa menor; a última conhece a resposta e as respostas voltam pela corrente.

Onde a comparação deixa de servir: A corrente só termina se a entrada se aproximar do caso de parada; pessoas na analogia não corrigem um domínio errado.

Ligar a ideia aos termos técnicos

O fatorial satisfaz f(0)=1 e f(n)=n*f(n-1) para n positivo. O caso base encerra a recursão. A correção segue por indução: se a chamada menor calcula (n-1)!, multiplicar por n calcula n!.

Ao ensinar, explique cada termo que usar. Se um nome técnico substituir a explicação, registre-o como lacuna.

O arquivo Python continua com uma linha

Salve como examples/11.py. A explicação pode usar várias linhas; a regra de compactação vale para o arquivo Python.

Baixar .py
fat=lambda n:1 if n==0 else n*fat(n-1);print(fat(6))

Acompanhe o mecanismo

  1. fat(6) precisa de 6*fat(5); as chamadas continuam até fat(0).
  2. fat(0) devolve 1. Cada chamada pendente multiplica esse resultado pelo seu n.
  3. As respostas retornam como 1, 1, 2, 6, 24, 120 e 720.

Antes de conferir, preveja o que aparece no terminal e explique por quê. Execute com python examples/11.py.

Conferir a saída esperada
720

Compare também seu raciocínio com os passos acima; acertar por palpite não explica o mecanismo.

4. Encontre uma lacuna e volte ao mecanismo

Pergunta para testar sua explicação: Por que a definição não serve diretamente para n=-1?

Investigar a lacuna depois de tentar

Subtrair 1 de um negativo o afasta de zero. O caso de parada nunca é alcançado por essa regra.
