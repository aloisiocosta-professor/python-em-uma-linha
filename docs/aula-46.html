Máquina virtual de pilha

Uma máquina virtual possui instruções, estado e regras de transição. PUSH empilha um operando e ADD combina os dois valores do topo. O significado de um programa é a execução dessas regras.

Objetivo desta aula

Explicar máquina virtual de pilha, prever o resultado do exemplo e modificar uma hipótese de entrada sem romper a regra de uma linha física.

Seu arquivo de uma linha

Salve como examples/46.py. A rolagem ou quebra visual na tela não muda o arquivo.

Baixar .py
exec("pilha=[];programa=[('PUSH',2),('PUSH',3),('ADD',None)]\nfor op,arg in programa:\n if op=='PUSH':pilha.append(arg)\n elif op=='ADD':b=pilha.pop();a=pilha.pop();pilha.append(a+b)\n else:raise ValueError(op)\nprint(pilha)")

Leia e execute

O arquivo chama exec com uma string autoral. Dentro dela, cada \n representa uma quebra lógica e os espaços seguintes representam indentação. Leia a sequência interna de cima para baixo, como um programa convencional.

No terminal: python examples/46.py. Compare o resultado com o oráculo abaixo antes de modificar o programa.

Exercício

Que instruções calculam (2+3)+4?

Conferir resposta comentada

Depois do primeiro ADD, acrescente PUSH 4 e ADD.

Hipóteses e limites

Um programa malformado pode causar underflow; um verificador estático é uma extensão.

A validação executável comprova este exemplo no ambiente registrado. Ela não substitui a demonstração geral de um algoritmo nem uma investigação empírica do problema real.
