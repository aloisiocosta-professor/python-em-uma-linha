Listas e compreensão

Uma lista guarda uma sequência mutável de referências. Uma compreensão constrói uma nova lista percorrendo uma fonte; o if filtra os itens antes de calcular a expressão de saída.

Objetivo desta aula

Explicar listas e compreensão, prever o resultado do exemplo e modificar uma hipótese de entrada sem romper a regra de uma linha física.

Seu arquivo de uma linha

Salve como examples/06.py. A rolagem ou quebra visual na tela não muda o arquivo.

Baixar .py
xs=range(6);print([x*x for x in xs if x%2==0])

Leia e execute

Leia as instruções separadas por ; da esquerda para a direita. Dentro de uma chamada, os argumentos são avaliados antes de a função ser executada. Uma compreensão percorre a fonte e aplica seu filtro antes da transformação.

No terminal: python examples/06.py. Compare o resultado com o oráculo abaixo antes de modificar o programa.

[0, 4, 16]

Exercício

Inclua todos os números, sem filtro.

Conferir resposta comentada

Remova if x%2==0; o resultado é [0, 1, 4, 9, 16, 25].

Hipóteses e limites

range(6) termina em 5; não inclui 6.

A validação executável comprova este exemplo no ambiente registrado. Ela não substitui a demonstração geral de um algoritmo nem uma investigação empírica do problema real.
