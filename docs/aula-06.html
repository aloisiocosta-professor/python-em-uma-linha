2. Entenda a ideia antes do código

Percorremos os números, perguntamos se cada um é par e guardamos o quadrado apenas dos que passam no teste.

Palavras desta aula

Lista

Compreensão
Expressão que constrói uma coleção percorrendo uma fonte.
for e in
Neste uso, indicam um nome corrente e a fonte que será percorrida.

Uma comparação familiar

Uma esteira passa peças por uma inspeção; somente as aprovadas seguem para a transformação.

Onde a comparação deixa de servir: O filtro e a transformação são expressões escritas pelo programador; a compreensão não descobre critérios sozinha.

Ligar a ideia aos termos técnicos

Uma lista guarda uma sequência mutável de referências. Uma compreensão constrói uma nova lista percorrendo uma fonte; o if filtra os itens antes de calcular a expressão de saída.

Ao ensinar, explique cada termo que usar. Se um nome técnico substituir a explicação, registre-o como lacuna.

Use Python para conferir seu raciocínio

O exemplo está em uma linha física. A explicação tem o espaço necessário. Primeiro acompanhe a ideia; não é preciso decorar essa escrita. Aprender a criar e executar um arquivo.

Baixar .py
xs=range(6);print([x*x for x in xs if x%2==0])

Acompanhe o mecanismo

  1. range(6) fornece 0, 1, 2, 3, 4 e 5.
  2. O filtro x%2==0 aceita 0, 2 e 4.
  3. x*x transforma os aceitos em 0, 4 e 16, que formam uma nova lista.

Antes de conferir, preveja o resultado e explique por quê. Se baixou só este arquivo, use python 06.py no terminal da pasta onde o salvou. Se obteve o repositório inteiro, use python examples/06.py na pasta principal. Use o nome de comando Python 3 identificado na preparação.

Conferir a saída esperada
[0, 4, 16]

range(6) para antes de 6. O filtro só pode selecionar os valores que a fonte forneceu.
