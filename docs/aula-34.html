Ligar a ideia aos termos técnicos

Monte Carlo aproxima uma esperança por média de amostras. Para U uniforme em [0,1), E[U]=1/2. Uma semente registra uma escolha do gerador, enquanto o erro amostral permanece parte do experimento.

Ao ensinar, explique cada termo que usar. Se um nome técnico substituir a explicação, registre-o como lacuna.

O arquivo Python continua com uma linha

Salve como examples/34.py. A explicação pode usar várias linhas; a regra de compactação vale para o arquivo Python.

Baixar .py
import numpy as np;rng=np.random.default_rng(42);x=rng.random(10000);print(bool(abs(x.mean()-0.5)<0.02))

Acompanhe o mecanismo

  1. default_rng(42) inicia um gerador com a semente registrada.
  2. random(10000) produz amostras uniformes entre 0, inclusive, e 1, exclusive.
  3. A média fica a menos de 0.02 de 0.5 nesta execução, por isso print mostra True.
