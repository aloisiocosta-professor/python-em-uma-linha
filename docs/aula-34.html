Monte Carlo e incerteza

Monte Carlo aproxima uma esperança por média de amostras. Para U uniforme em [0,1), E[U]=1/2. Uma semente registra uma escolha do gerador, enquanto o erro amostral permanece parte do experimento.

Objetivo desta aula

Explicar monte carlo e incerteza, prever o resultado do exemplo e modificar uma hipótese de entrada sem romper a regra de uma linha física.

Seu arquivo de uma linha

Salve como examples/34.py. A rolagem ou quebra visual na tela não muda o arquivo.

Baixar .py
import numpy as np;rng=np.random.default_rng(42);x=rng.random(10000);print(bool(abs(x.mean()-0.5)<0.02))

Leia e execute

Leia as instruções separadas por ; da esquerda para a direita. Dentro de uma chamada, os argumentos são avaliados antes de a função ser executada. Uma compreensão percorre a fonte e aplica seu filtro antes da transformação.

No terminal: python examples/34.py. Compare o resultado com o oráculo abaixo antes de modificar o programa.

True

Exercício

Um único True prova qualidade do gerador?

Conferir resposta comentada

Não; é apenas uma checagem desta amostra e desta tolerância.

Hipóteses e limites

Não há garantia universal de amostras idênticas entre todas as versões; registre o ambiente.

A validação executável comprova este exemplo no ambiente registrado. Ela não substitui a demonstração geral de um algoritmo nem uma investigação empírica do problema real.
