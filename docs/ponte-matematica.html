Esta página prepara o vocabulário matemático das demonstrações. Faça as contas no papel e explique o motivo de cada passo; os temas avançados exigem aprofundamento além desta introdução.

Frações, decimais e tolerância

Uma fração a/b representa uma razão; b precisa ser diferente de zero. 1/10 é um décimo, escrito 0,1 no uso decimal brasileiro. Python usa ponto para esse literal: 0.1. Algumas representações numéricas guardam aproximações. Uma tolerância declara quanta diferença aceitamos ao comparar duas respostas.

Explique sem consultar: por que duas aproximações podem não ser exatamente iguais? Conferência: arredondamentos podem diferir, mesmo quando as quantidades pretendidas coincidem. Isso não autoriza escolher qualquer tolerância; ela depende do problema.

Média e desvios

A média aritmética soma os valores e divide pela quantidade. Para 1 e 3, é (1+3)/2=2. O desvio de cada valor em relação à média é valor menos média: -1 e 1. Média de uma lista vazia requer uma decisão; não podemos dividir por zero.

Funções, potências e raízes

Uma função relaciona uma entrada a uma saída conforme uma regra. f(x)=x² multiplica x por si mesmo. Para x=3, f(x)=9. Uma raiz da equação x²-2=0 é um valor que a torna verdadeira. Há duas raízes reais, positiva e negativa; o intervalo escolhido na demonstração de bisseção seleciona a positiva.

Encontre uma lacuna: dizer que 1,4 é “a raiz exata” está correto? Não: 1,4²=1,96. É uma aproximação, cujo erro precisa ser considerado.

Vetores, matrizes e equações simultâneas

Um vetor pode organizar componentes numa sequência, como (x,y). Uma matriz organiza coeficientes numa tabela. O sistema 2x+y=5 e x+3y=5 pede um par que satisfaça ambas. (2,1) funciona: 2*2+1=5 e 2+3*1=5. Na forma A@v, cada linha combina seus coeficientes com o vetor. Não basta satisfazer apenas uma equação.

Probabilidade e amostras

Uma distribuição descreve como valores podem ocorrer. No modelo uniforme entre 0 e 1, intervalos de mesmo comprimento têm a mesma probabilidade. A média teórica é 0,5. Uma amostra finita não precisa ter exatamente essa média; repetir uma amostra com semente fixa não elimina a incerteza do procedimento.

Taxa de variação e derivada

Se uma quantidade muda 6 unidades em 3 segundos, a taxa média é 2 unidades por segundo. A derivada descreve uma taxa local, perto de um ponto. Para f(x)=x², a derivada é 2x. Isso pode ser visto por ((x+h)²-x²)/h=2x+h para h diferente de zero, que se aproxima de 2x quando h se aproxima de zero.

Na equação y′=−y, a taxa de mudança é negativa e proporcional à quantidade atual. Com y(0)=1, a solução é exp(−t); exp usa a base e, aproximadamente 2,71828. A condição inicial escolhe uma trajetória entre as admitidas pela equação. Para dominar esses argumentos, estude limites e cálculo antes de tratar sistemas mais gerais.

Números complexos e frequência

Um número complexo é escrito a+bi, com i²=−1. Ele conserva duas componentes e permite representar amplitude e fase de oscilações. Frequência descreve quantos ciclos ocorrem por unidade. A DFT representa uma sequência finita por componentes complexas; descartar componentes sem justificativa pode impedir a reconstrução. A demonstração de Fourier verifica apenas uma transformação de ida e volta.

Como usar esta ponte

Escolha um conceito, crie um exemplo com seus números, explique a regra e verifique uma conta. Registre onde faltou compreensão e investigue antes de avançar. Saber repetir o nome de uma fórmula não significa conseguir aplicá-la. Voltar ao mapa.
